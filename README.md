# JobRate

Расширение для браузера, которое сравнивает вакансию на странице с вашим резюме
и показывает процент соответствия, а также какие навыки есть, а каких не хватает.

- **Backend**: Python (FastAPI + SQLAlchemy). Сопоставление навыков — полностью
  локальное и бесплатное, без внешних API: резюме и вакансия прогоняются через
  встроенный словарь навыков (`app/services/skills_dictionary.py`) с алиасами/синонимами.
- **Extension**: чистый JS/HTML/CSS под Chrome/Edge (Manifest V3), без сборщиков —
  устанавливается как "распакованное расширение".

Ключи API не нужны, платить никому не надо — всё работает офлайн на вашей машине.

## 1. Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

`.env` не обязателен — по умолчанию используется SQLite-файл `backend/jobrate.db`.
Если нужно переопределить путь к БД, скопируйте `.env.example` в `.env` и поправьте `DATABASE_URL`.

Запуск сервера:

```bash
uvicorn app.main:app --reload --port 8000
```

Проверка: [http://localhost:8000/health](http://localhost:8000/health) должен вернуть `{"status":"ok"}`.
При первом запуске автоматически создастся файл БД `backend/jobrate.db` (SQLite).

## 2. Extension

1. Откройте `chrome://extensions` в Chrome (или `edge://extensions` в Edge).
2. Включите режим разработчика ("Developer mode").
3. Нажмите "Загрузить распакованное расширение" ("Load unpacked").
4. Выберите папку `extension/`.

## 3. Использование

1. Откройте попап расширения (иконка в панели браузера) — загрузите PDF/DOCX/TXT резюме.
   Бэкенд найдёт в тексте навыки из словаря и покажет их в попапе; список можно
   редактировать вручную (введённые вручную названия тоже сверяются со словарём —
   например, "js" превратится в "JavaScript").
2. Откройте страницу вакансии (например, на hh.ru, LinkedIn, Indeed) — если страница
   похожа на вакансию, в правом нижнем углу появится виджет с процентом соответствия
   и списками "есть у вас" / "не хватает".

## Как считается процент

Никакого ИИ — простой прозрачный алгоритм:
1. Из текста вакансии через regex по словарю навыков извлекается список требуемых навыков.
2. Он сравнивается со списком навыков в профиле (точное совпадение канонического названия).
3. `match_percent = (совпавшие / все требуемые в вакансии) × 100`.

Качество результата напрямую зависит от полноты словаря в `skills_dictionary.py` —
его легко расширять, просто добавляя новые записи `"Канонiческое имя": ["алиас1", "алиас2"]`.

## Структура проекта

```
backend/
  app/
    routers/     # HTTP-эндпоинты: /api/cv, /api/profile, /api/match
    services/
      skills_dictionary.py  # словарь навыков + алиасы, regex-поиск по тексту
      matcher.py              # извлечение навыков из резюме, подсчёт match_percent
      resume_parser.py         # парсинг PDF/DOCX/TXT в текст
    models.py      # SQLAlchemy-модели (Profile, Skill, MatchHistory)
    schemas.py      # Pydantic-схемы запросов/ответов
    main.py          # точка входа FastAPI
extension/
  manifest.json
  background.js   # service worker: HTTP-запросы к бэкенду
  content.js       # определяет страницу вакансии, показывает виджет
  popup.html/js/css # загрузка резюме, редактирование навыков
```

## Дальнейшие шаги (не реализовано в MVP)

- Расширение словаря навыков (сейчас ~120 записей) — главный рычаг повышения точности.
- Сайт-специфичные экстракторы текста вакансии (hh.ru, LinkedIn, Indeed) вместо
  общей эвристики.
- Многопользовательский режим с аутентификацией (сейчас один профиль на инстанс backend).
- История откликов/совпадений в отдельном разделе попапа (таблица `MatchHistory` уже пишется).
- Сборка под Firefox.
- Опционально можно вернуть сопоставление через LLM (Claude API) как более точный,
  но платный режим — например, переключаемый флагом в `.env`.
